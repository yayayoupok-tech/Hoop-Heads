# Face construction reference (L14)

`face-construction.png` is the front-view face construction every Hoop Heads face is built on, drawn by the game
itself (Art Lab → Symmetry, pages 4–6 draw the same guides over the 12 cast faces). The playtest spec asked for visual
rounds "against reference/", but the repository had no reference folder, so this sheet was made from the spec's
proportions. The spec calls for the construction of Basketball Legends / Basketball Bros (big front-facing heads) with
original characters only, so no images from those games are used here.

Proportions (u = head width; heights from the crown, as a share of crown-to-chin):

| Feature | Construction |
| --- | --- |
| eyes | centers at ±0.19 u on the 46% line; 0.19 × 0.13 u; iris 0.07 u |
| brows | 0.05 u above the eyes |
| nose | tip centered on the 62% line; nostrils at ±0.05 u; no profile line |
| mouth | centered on the 74% line; 0.34 u wide (a grin 0.42 u); even teeth |
| ears | both, 0.10 × 0.16 u, between the eye and nose lines |
| jaw | 0.80 u |

A face is built as one half and mirrored. Facing slides the eyes, nose and mouth at most 0.04 u toward the facing side
(0 on this sheet). The face parameters (eye size and spacing, nose and mouth width, ear size, jaw, chin, cheeks,
forehead, head width) vary each face around these lines.
